# Weather Tracker

Невеликий навчальний проєкт: сайт для перегляду поточної погоди, погодинного
та тижневого прогнозу.

## Що всередині

- `index.html` — структура сторінки
- `styles.css` — весь дизайн і адаптивність
- `app.js` — логіка пошуку міст, запити до API та оновлення інтерфейсу

## Як запустити

1. Відкрийте `index.html` у браузері.
2. Введіть назву міста або натисніть `Моє місце`.
3. За бажанням збережіть місто у список під рукою.

## Що тут корисно для навчання

- робота з `fetch` і зовнішнім API
- робота з формами та подіями
- оновлення DOM через JavaScript
- збереження даних у `localStorage`
- адаптивна верстка без фреймворків

## Ідеї для наступних кроків

- додати перемикач між `°C` і `°F`
- показувати кілька міст одночасно
- додати графік температури
- зробити теми `день/ніч`
- винести запити до API в окремий модуль
